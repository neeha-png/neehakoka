# Phase 2: Design Documentation

## 🎨 Color Palette
To ensure a clean, modern, tech-focused look that passes WCAG AA contrast rules, the site uses the following color tokens:

### Dark Theme (Default)
* **Background:** Charcoal / Deep Slate (#121826)
* **Text / Foreground:** Off-White (#F3F4F6)
* **Accent Color:** Electric Blue (#3B82F6) — Used for links and buttons.

### Light Theme
* **Background:** Pure White (#FFFFFF)
* **Text / Foreground:** Dark Slate (#1F2937)
* **Accent Color:** Deep Blue (#2563EB)

---

## 🔤 Typography
* **Font Family:** System Sans-Serif font stack (`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`). 
  * *Rationale:* This ensures fast loading times because the browser doesn't have to download heavy external font files, keeping performance high.
* **Scale:**
  * **H1 (Main Titles):** 2.25rem (36px) / Bold
  * **H2 (Section Headings):** 1.5rem (24px) / Semi-Bold
  * **Body Text:** 1rem (16px) / Regular

---

## 📐 Spacing System
A strict 8px grid system is used to handle margins and paddings consistently across mobile and desktop views:
* `8px` (Small gaps, tight padding)
* `16px` (Standard component padding)
* `24px` (Spacing between smaller text blocks)
* `32px` (Standard layout spacing between sections)
