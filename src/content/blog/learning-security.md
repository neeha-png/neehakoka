# Exploring Secure Systems Design

As a fresher starting out in software development, it is easy to focus only on making visual elements look nice. However, building secure applications matters just as much.

## Form Security
When building a public-facing page like a contact form, server-side data checking is critical. If you don't validate user inputs, malicious actors can spam or exploit your application infrastructure. 

Over the next few days, I will be writing code to ensure my backend endpoints handle incoming data securely.
